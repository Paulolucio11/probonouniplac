COMO ATIVAR O ENVIO AUTOMÁTICO
1. Abra https://script.google.com/ com a conta Google responsável pelo projeto.
2. Crie um novo projeto de Apps Script.
3. Cole o conteúdo de apps_script/Code.gs no arquivo Code.gs.
4. Salve o projeto.
5. Em Deploy > New deployment, escolha Web app.
6. Execute como você (a conta responsável pelo projeto).
7. Em acesso, permita que qualquer pessoa possa acessar o web app, pois o formulário público precisa enviar a solicitação sem login.
8. Clique em Deploy e copie a Web app URL, que termina em /exec.
9. No index.html, substitua COLE_AQUI_A_URL_DO_APPS_SCRIPT pelo endereço /exec.
10. Atualize o index.html no mesmo repositório GitHub Pages.
11. Faça um teste real pelo site público.

OBSERVAÇÃO DE SEGURANÇA
O e-mail recebido terá apenas os dados básicos do formulário. Não solicitar CPF, documentos, endereço completo ou detalhes excessivos de caso no formulário público.

ATUALIZAÇÕES
O endereço do site GitHub Pages permanece o mesmo quando os arquivos do mesmo repositório são atualizados.
